The Subdomain Is the Frequency

How this works

Put any number in front of the domain and the generator opens tuned to it: 440.1khz.sh is concert A, 60.1khz.sh is mains hum, 16k.1khz.sh is a hearing test you'll wish you hadn't run. DNS labels can't contain a dot, so a dash stands in for the decimal point — 432-5.1khz.sh lands on 432.5 Hz.

There's no server trickery involved. A wildcard DNS record points every subdomain at the same static files, and a few lines of JavaScript read window.location.hostname and set the dial. Nothing is looked up, nothing is logged beyond the request itself, and the same page works with the network off — see how to verify all of that.

Every number on this page is worked out in your browser. No accounts, no cookies, no analytics, no backend — nothing you type is sent anywhere, and the kit keeps working with the network off. Free and open source under the MIT licence.
