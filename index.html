The Subdomain Is the Frequency

How this works

Put any number in front of the domain and the generator opens tuned to it: 440.1khz.sh is concert A, 60.1khz.sh is mains hum, 16k.1khz.sh is a hearing test you'll wish you hadn't run. DNS labels can't contain a dot, so a dash stands in for the decimal point — 432-5.1khz.sh lands on 432.5 Hz.

There's no server trickery involved. A wildcard DNS record points every subdomain at the same static files, and a few lines of JavaScript read window.location.hostname and set the dial. The sibling domain 2khz.sh just redirects here preset to 2 kHz, because of course it does.

No ads, no tracking, no backend — the whole kit runs in your browser. If it saved a soundcheck, you can chip in for the domains.

Tip: any number works as a subdomain — 60.1khz.sh is mains hum.
